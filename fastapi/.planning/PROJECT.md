# Манифест задачи

- **task_id:** BILL-FREE01
- **Feature Name:** free-plan-link-limit-v3
- **Источник:** specs/billing-ears.md `[REQ-EARS-07]` — ПОКА тарифный план равен FREE, система ДОЛЖНА ограничивать число платных ссылок до 10.

## Цель
При создании платной ссылки пользователь с планом FREE не может превысить 10 активных ссылок; 11-я и далее отклоняются доменной ошибкой → HTTP 403 (занавес квоты).

## Границы (Out of Scope)
- Тарифные переходы (upgrade/downgrade), биллинг самой смены плана.
- Лимиты для PRO/ENTERPRISE (кроме подтверждения, что их не трогает).
- Пагинация/аудит (v2-долг в accepted_debt).

## Нерушимые правила
1. Замороженное ядро: `app/core/config.py`, `app/core/security.py`, `app/main.py`.
2. Бюджет волны: ≤ 7 файлов (specs/blast-radius.json).
3. Rule Filing Back: изменение контракта — в `docs/domains/billing.md`.
4. Слой API не содержит бизнес-логики; SQL/кнопка — в репозитории; проверка квоты — в сервисе.
