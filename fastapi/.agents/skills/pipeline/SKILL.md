# Скил pipeline: кодер, ревьюер, панель

Триггер: фича по спеке из docs/spec-*.md.

Роли и порядок: Coder (пишет) → CODE_GATE (гейты) → Reviewer (читает, блокирует) →
исправления → Gate-панель из трёх независимых сессий (голосование 2/3).

CODE_GATE: ruff, basedpyright, pytest, git diff --check. Красный гейт
возвращает Coder, а не идёт дальше.

Reviewer стартует свежей сессией, без истории Coder. Получает только спеку,
diff и логи. Формат итога: вердикт ACCEPT или CHANGES_REQUESTED плюс находки
с файлом и строкой.

Лимит: не больше 3 возвратов Coder. Дальше эскалация человеку.

Gate-панель: три свежие сессии, каждая читает только пакет (спека, diff, логи,
handoff) и пишет вердикт READY или REWORK. Итог по большинству: 2-3 READY из 3
принимает работу, 0-1 READY возвращает на доработку, разошедшаяся сессия
перезапускается один раз.

Выход: схема конвейера, лог итераций, риск-план QA, вердикт Gate-панели (3 голоса).
