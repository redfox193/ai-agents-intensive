# Скил: architecture-layers-linter

## 1. Назначение и триггеры

Скил предотвращает превращение монолита в спагетти-архитектуру (Big Ball of Mud). Проверяет направления всех импортов в кодовой базе и намертво блокирует несанкционированные связи между слоями.

**Триггеры запуска:**
- Завершение любой фазы написания кода.
- Перед запуском юнит- и интеграционных тестов.
- Пре-коммит хук и финальный Techlead Gate.

---

## 2. Предусловия (Inputs)

1. Исходный код монолита в директории `app/`.
2. Доступен скрипт `tools/verify_architecture_layers.py`.

---

## 3. Пошаговая процедура (Execution Steps)

### Фаза 1: Сканирование AST-деревьев модулей
1. Запустить архитектурный линтер:
   ```bash
   python3 tools/verify_architecture_layers.py
   ```
2. Анализатор обходит все узлы `ast.Import` и `ast.ImportFrom`.

### Фаза 2: Проверка 3 ключевых правил изоляции
1. **Правило Schemas:** `app/schemas/` не содержит импортов из `app.services`, `app.api`, `app.core`.
2. **Правило Services:** `app/services/` не содержит импортов фреймворка `fastapi`, `starlette` и слоя `app.api`.
3. **Правило API:** `app/api/` не содержит прямых импортов базы данных `app.core.database` (доступ строго через сервисы).

### Фаза 3: Устранение нарушений
1. При обнаружении ошибок линтер выводит точный файл и запрещенный импорт.
2. Агент устраняет нарушение переносом логики в соответствующий слой или внедрением `typing.Protocol`.

---

## 4. Выходные артефакты (Outputs)

1. Отчет проверки архитектурных слоев (stdout/stderr).
2. Код возврата: 0 — чисто, 1 — архитектурные нарушения.

---

## 5. Ворота готовности (Definition of Done)

- [ ] Скрипт `tools/verify_architecture_layers.py` завершился с кодом 0.
- [ ] Однонаправленный граф (DAG: schemas -> core -> services -> api) строго соблюден.
- [ ] В слое сервисов нет ни одного импорта `HTTPException`.

---

## 6. Стоп-условия и откат

- **Стоп-условие 1:** Попытка обойти линтер через динамический `importlib.import_module`. Блокировка коммита.
- **Стоп-условие 2:** Попытка поместить `fastapi` в сервисный слой ради быстрого статус-кода. Откат правки.
