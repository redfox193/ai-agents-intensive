# Скил: blast-radius-guard

## 1. Назначение и триггеры

Скил предотвращает неконтролируемое расползание правок по монолиту и защищает критическую инфраструктуру от случайных модификаций AI-агентами.

**Триггеры запуска:**
- Перед каждым коммитом в Git.
- При завершении волны изменений.
- В составе автоматического шлюза техлида.

---

## 2. Предусловия (Inputs)

1. Спецификация ограничений `specs/blast-radius.json`.
2. Конфигурация владельцев кода `.github/CODEOWNERS`.
3. Утилита `tools/verify_blast_radius.py`.

---

## 3. Пошаговая процедура (Execution Steps)

### Фаза 1: Анализ рабочей зоны Git
1. Запустить верификатор радиуса изменений:
   ```bash
   python3 tools/verify_blast_radius.py
   ```
2. Утилита запрашивает `git status --porcelain -uall` (новые файлы в новых каталогах считаются поштучно) и учитывает переименования `R  старый -> новый`.

### Фаза 2: Проверка бюджета файлов
1. Подсчитать число модифицированных файлов проекта.
2. Сверить с лимитом `max_changed_files` из `specs/blast-radius.json` (по умолчанию 7 файлов).
3. При превышении бюджета — коммит блокируется.

### Фаза 3: Контроль неприкосновенности ядра
1. Проверить пути измененных файлов по списку защищенных директорий:
   - `app/core/`
   - `alembic/`
2. Если затронут файл ядра или файл из `frozen_paths` — немедленный отказ (`PROTECTED FILE MODIFIED`). Новый файл в `app/core/` допустим только из списка `allowed_new_core_files` спеки (сейчас `app/core/protocols.py`, волна 2).

---

## 4. Выходные артефакты (Outputs)

1. Протокол проверки Blast Radius с перечнем модифицированных файлов.
2. Код возврата 0 при соблюдении бюджета.

---

## 5. Ворота готовности (Definition of Done)

- [ ] Число измененных файлов строго ≤ 7.
- [ ] Ни один файл в `app/core/` не был изменен.
- [ ] Скрипт `tools/verify_blast_radius.py` вернул PASS (exit 0).

---

## 6. Стоп-условия и откат

- **Стоп-условие 1:** Агент попытался изменить файл ядра, например `app/core/config.py`. Немедленный откат файла `git checkout app/core/config.py`.
- **Стоп-условие 2:** Число измененных файлов превысило 7. Разделение задачи на две независимые волны.
