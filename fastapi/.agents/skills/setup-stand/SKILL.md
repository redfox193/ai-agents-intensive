# Скил: setup-stand (Подготовка стенда Дня 3)

## Процедура
1. Стянуть ветку Дня 3 и теги контрольных точек с сервера:
   ```bash
   git fetch origin day-3 --tags
   ```
2. Переключиться на рабочую ветку Дня 3:
   ```bash
   git checkout -f day-3
   ```
3. Создать локальный файл конфигурации `.env` из шаблона при отсутствии:
   ```bash
   test -f .env || cp .env.example .env
   ```
4. Синхронизировать виртуальное окружение и зависимости:
   ```bash
   uv sync
   ```
5. Выполнить проверочный запуск тестов:
   ```bash
   uv run pytest tests/unit -q
   ```

## Критерий готовности (DoD)
- Текущая ветка строго `day-3`.
- Теги `snap-0` … `snap-6` доступны локально.
- Все юнит-тесты завершаются успешно (код 0).
