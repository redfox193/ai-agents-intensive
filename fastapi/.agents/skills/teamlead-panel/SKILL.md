# Панель техлидов: 3 свободных модели OpenCode

Панель техлидов обеспечивает независимую коллегиальную приёмку кода без дорогостоящих проприетарных подписок, используя пул доступных свободных моделей OpenCode.

## Состав коллегии и шляпы

Каждый судья запускается изолированным процессом в режиме STRICT READ-ONLY (`< /dev/null`):

1. **Judge 1 (`opencode-go/deepseek-v4.1-flash`) — Шляпа: Скептик**
   - Фокус: риски безопасности, утечки авторизации (CWE-532), граничные случаи, необработанные ошибки (402, 503).
2. **Judge 2 (`opencode-go/glm-5.3-flash`) — Шляпа: Реалист**
   - Фокус: строгое соответствие спецификации EARS, простота решения, проверяемость модульными и интеграционными тестами.
3. **Judge 3 (`opencode-go/qwen3.8-flash`) — Шляпа: Визионер**
   - Фокус: соблюдение границ архитектурных слоёв (`schemas -> core -> services -> api`), технический долг, чистота контрактов (PEP 544).

## Встроенная функция: panel-rework-summarizer

При наличии замечаний хотя бы у одного судьи запускается суммаризатор на модели `opencode-go/glm-5.3-flash`:
- Собирает замечания всех судей (`.ai-team/panel/judge-*.json`).
- Устраняет дубликаты.
- Формирует файл `handoff/panel-rework-brief.json` со списком инструкций `RW-001`, `RW-002`... с точным указанием файла, строки и требуемого действия для Кодера.

## Правило вынесения вердикта

- **ACCEPT (`READY`):** все 3 судьи дали `ACCEPT`, либо отсутствуют находки тяжести `BLOCKER` и `IMPORTANT`.
- **REJECT (`REWORK`):** есть хотя бы одна находка уровня `BLOCKER` или `IMPORTANT`. Сформирован бриф для Кодера.
- **ESCALATE:** сбой доступности моделей, повреждение файлов артефактов или превышение лимита циклов.
