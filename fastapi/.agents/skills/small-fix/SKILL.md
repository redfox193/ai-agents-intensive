# Скил small-fix

Триггер: точечная правка в linksvc в пределах 1-2 файлов.

Входы: описание задачи, затронутые пути, критерий готовности.

Шаги:
1. Прочитай AGENTS.md и docs/module-map.md.
2. Сними baseline: uv run pytest tests/flat_api/test_characterization.py -q.
3. Внеси правку в разрешённых путях, не трогай защищённые.
4. Прогони ruff, basedpyright, pytest. Красный гейт чини кодом.
5. Запиши итог: diff, команды, коды выхода, что не смотрел.

Выход: патч в ветке feature/* плюс отчёт из пункта 5.

Критерий готовности: characterization зелёный, гейты 0, отчёт на диске.

Стоп-условия: затронуто больше 2 файлов; гейт красный после 3 попыток;
нужен доступ к секретам. Во всех случаях остановись и опиши состояние.
