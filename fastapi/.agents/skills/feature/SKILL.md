# Скил feature: Кодер, Цикл 1

Скил для первого запуска Кодера в внешнем цикле `teamlead-gate`. Кодер получает brief от Оркестратора, реализует задачу в пределах Blast Radius и сдаёт handoff. Приёмку делает не Кодер: CODE_GATE и Панель техлидов проверят результат независимо. Запуск: `opencode run -m "${OPENCODE_MODEL:-opencode/deepseek-v4.1-flash-free}" "<brief>" < /dev/null` (семейство `deepseek-v4.1`, свежий процесс).

## Вход (brief Оркестратора)

| Поле | Что это |
|---|---|
| `task_id` | идентификатор задачи |
| цель | что должно появиться в поведении сервиса |
| `spec_refs` | пути к спеке |
| `risk_plan_ref` | путь к риск-плану |
| `allowed_paths` | Blast Radius: менять можно только эти пути |
| `protected_paths` | трогать нельзя (защитные тесты, `AGENTS.md`, конфигурация подключения к БД) |
| AC | по каждому критерию: `id`, `current`, `expected`, `unchanged`, `command`, `expected_exit` |
| антипримеры | чего делать не надо |
| обязательные гейты | команды, которые должны вернуть 0 |

Нет любого обязательного входа — не угадывай, остановись и ответь строкой `ASK: <имя поля>`.

## Порядок реализации по слоям

Идти строго по порядку, трогая только затронутые слои и только разрешённые пути:

1. **domain** — типы и правила предметной области (если слой есть в задаче).
2. **models** — `app/models/`: поля модели.
3. **repositories** — `app/repositories/`: запросы к БД. SQL живёт только здесь.
4. **services** — `app/services/`: бизнес-правила.
5. **api** — `app/api/` и `app/main.py`: эндпоинты, которые вызывают сервис и не содержат SQL и транзакций.
6. **alembic** — `alembic/versions/`: миграция, если схема меняется (с `server_default` для новых колонок).

Нерушимое правило слоёв: API вызывает сервис, сервис вызывает репозиторий, обратной зависимости нет.

## Тесты и личный прогон

1. Тесты по риск-плану: для каждого риска сначала тест, который падает (red), затем код, после которого он зелёный (green).
2. Личный прогон до сдачи: `uv run ruff check app tests`, `uv run basedpyright`, `uv run pytest tests/ -v`. Он не заменяет CODE_GATE Оркестратора: тот запустит всё заново и поверит только своим кодам выхода.
3. Проверки не ослаблять: не добавлять `skip`, `xfail`, `noqa`, `type: ignore` ради зелёного цвета, не править ожидания тестов под баг.
4. Не трогать `AGENTS.md` и защитные тесты (слепок поведения, который ломать нельзя).
5. Zero Auth Leak (CWE-532): токены, `Authorization` и `target_url` не попадают в логи и вывод.

## Зелёный тулчейн не равен бизнес-результату

- **Дефолт не должен выключать саму фичу.** Если параметр управляет тем, ради чего фича существует, он либо обязательный, либо его значение по умолчанию рабочее. Ноль, пустая строка и `None` в таком поле — выключатель под видом настройки.
- **Тест на фактический payload,** а не на код возврата: проверь, что во внешний вызов или ответ ушло рабочее значение. Ответ 200 ничего не доказывает, если фича попросила «ничего не делать».
- **Проверь живую ручку:** вызови настоящий эндпоинт (HTTP → сервис → БД) и сравни результат с ожиданием из спеки, а не с «непусто и без ошибки».
- Новый параметр окружения должен быть описан там, где его читают другие параметры проекта.

## Выход

1. `handoff/coder-01.json`: `schema_version` `1.1`, `task_id`, `author_role` `coder`, `cycle` 1, `mode` `feature`, `changed_files` (относительные пути без `..`), `artifacts`, `decisions`, `open_questions` (может быть пустым), `ac_results` (`id`, `status`, `command`, `exit_code`), `tests` (`command`, `exit_code`, `log_ref`), `risks`, `unchanged_checks`.
2. Проекция `.ai-team/handoff-coder.md` с заголовком `# Handoff Кодер → Панель техлидов` и разделами `Команды и коды выхода`, `Решения`, `Риски`, `Не смотрел`. Без плейсхолдеров и TODO; в «Не смотрел» честно перечисли, что не проверял.
3. Проверка формата: `python3 scripts/validate_handoff.py handoff/coder-01.json`.
4. Коммит в ветке `feature/*`, один на фичу:

```text
[agent] feat(<scope>): <описание на русском>
```

Тег и scope английские, описание русское. Если что-то упало нетривиально: назови причину, оцени масштаб и предложи варианты, не маскируй сбой обходным путём.
