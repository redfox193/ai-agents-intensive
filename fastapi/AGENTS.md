# Правила linksvc

1. Граница слоёв: хэндлеры (app/main.py, app/api/) тонкие, бизнес-правила живут в app/services/, SQL только в app/repositories/. Обращение к данным из хэндлера запрещено. Приложение (app/, alembic/) единое для трёх дней и доступно с Дня 1; контракт LINK-42 держат тесты tests/flat_api/.
2. Каждый шаг доказывается командой: ruff, basedpyright, pytest. Уверенный текст доказательством не считается.
3. Не ослабляй проверки, чтобы зазеленить. Красный гейт чинится кодом, а не порогом.
4. Не читай каталог docs/archive и файлы *.bak: там шум и устаревшее.
5. Секреты только в переменных окружения. Ключи и пароли в коде и логах запрещены.
6. Правка пишется в ветке feature/*, прямой коммит в main запрещён.
